# Trivia Duel

A quick-fire multiple-choice trivia game. Same questions, same clock — the fastest right answer scores the most points.

- 163 questions with a British flavour across General Knowledge, Science & Nature, Geography, History, Sport, Maths & Numbers, Words & Language, and Books, TV & Music
- Choose a category, 5–20 questions and 10–30 seconds per question
- 500 points for a correct answer plus up to 500 more for speed
- Solo practice mode

Live multiplayer (game codes) runs when the page is opened as a Claude artifact; on GitHub Pages the game runs in solo mode.
